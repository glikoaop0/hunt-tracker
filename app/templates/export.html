Database backup

A consistent point-in-time copy of the underlying SQLite database, taken with SQLite's own backup mechanism so it's safe even if the app is running. This is the most complete backup available; use it if you want a copy you could restore from later.

To restore manually: stop the application first. Make an additional copy of your current hunts.db before doing anything else, in case you need to go back. Then replace hunts.db in the project directory with the downloaded backup file (renamed to hunts.db), and start the application again. There is no restore option in the browser; this is a deliberate safeguard against overwriting your data by accident.
