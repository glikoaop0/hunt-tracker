Good to know

  • Past runs are safe. Each run keeps a snapshot of the query it used, so editing the query here does not rewrite run history.
  • Scheduling. Logging a run moves the next run forward by the cadence. Clearing the cadence makes the hunt one-off and clears the next run date.
  • Status and retirement. These are changed with the stage buttons on the hunt page, or by dragging the card on the board. Retiring asks for a reason.
  • Exclusions. Add or deactivate them on the hunt page, below the run history.
