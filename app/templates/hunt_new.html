From idea to recurring hunt

  1. Capture the idea. A title and a testable hypothesis are enough, e.g. "Attackers persist on Linux hosts through modified shell profile scripts." New hunts start in Idea.
  2. Scope it. Open the hunt and choose Edit hunt to add the query, data sources and ATT&CK techniques.
  3. Run it. Log each execution on the hunt page with an outcome. Set a cadence to make it recur; the next run date then advances on its own.
  4. Retire it. Drag the card to Retired on the board and record why: converted to a detection, hypothesis rejected, missing telemetry…
