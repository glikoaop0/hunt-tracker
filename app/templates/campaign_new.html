How campaigns work

  1. State the objective. Phrase it as the question the campaign should answer, e.g. "Is there evidence of unauthorised persistence on Linux servers?"
  2. Link hunts. After creating the campaign, add existing hunts from its page. A hunt can belong to several campaigns.
  3. Run and track. Runs logged on linked hunts appear in the campaign's Activity tab and status overview.
  4. Conclude. Write the conclusion and close the campaign. It can be reopened at any time.
